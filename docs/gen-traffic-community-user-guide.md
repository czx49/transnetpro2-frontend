# 生成交通小区 — 使用说明

## 功能作用

根据项目 **道路路段**（`road_way`）与 **人口栅格**，自动划分 **交通小区**（TAZ），并写入项目的 `road_community` 表。适用于尚未有小区、需按人口规模批量生成 TAZ 的场景。

## 入口

1. 打开项目 → 切换到 **基础数据** 页签  
2. 侧栏 **工具** → **生成交通小区**

## 前置条件

- 已登录，项目菜单中存在道路组下的 **road_way** 图层  
- 人口栅格默认路径：`{程序目录}/data/chn_pop_2024_CN_100m_R2025A_v1.tif`（单波段）  
- **不需要**事先加载或编辑 `road_community`（由服务端在提交后生成）

## 参数说明

| 参数 | 默认 | 含义 |
|------|------|------|
| 格网边长 (m) | 500 | 划分研究区的 fishnet 单元边长，越小格网越多、小区边界越细 |
| 路网缓冲半宽 (m) | 300 | 对路段做 buffer 的半径（总宽 = 2×半宽），用于确定可划分范围并填洞 |
| 目标人口 | 100000 | 每个交通小区希望容纳的人口规模 |
| 人口上限系数 | 1.3 | 单区人口上限 = 目标人口 × 系数；区域生长超过上限则开启新区 |
| 是否覆盖现有小区图层 | 勾选 | 未勾选时仅本地计算并显示格网数/小区数/人口合计，**不提交服务端**；勾选后提交并覆盖现有 `road_community` |

聚类采用**等距水滴扩张**：优先合并距离种子更近且相邻的格网，边界更接近圆形；小路网会为后续小区预留网格。

## 运行过程

弹窗会显示步骤：缓冲 → 格网 → 人口统计 → 裁剪 → 聚类 →（提交）。失败时弹窗内红字提示。

## 结果

- 成功：提示操作成功，地图自动加载 **road_community** 显示新小区面  
- 原 `road_community` 数据会被 **整表替换**（以服务端为准）

## 常见问题

- **找不到 road_way**：检查项目 detail 菜单道路组是否配置 `val=road_way`  
- **栅格不存在**：将人口 tif 放到程序目录下 `data/` 文件夹  
- **格网过多**：增大格网边长或缩小路网范围
